## Tabs

Opening a file from the [explorer](workbench-explorer) gives it a tab in IDE mode's centre; several
tabs sit in a strip along the top, one active at a time, each showing the viewer its kind needs —
plain text, a diagram, an image. Pin a tab to keep it out of a bulk "close others."

## Saving

Changes save with the usual keyboard shortcut, or by closing a tab, which asks first if it holds
unsaved edits.
