# Welcome to Ubiq

Ubiq is an **agentic workspace**: several AI coding agents — Claude Code, Codex, Gemini CLI,
opencode, Copilot CLI — side by side under one window, each in a real terminal of its own.

- **Agents run as themselves.** Every harness gets a full terminal, so it draws exactly what it
  would draw in yours, and you type to it directly.
- **Work is organised by project.** A project is a folder; the window shows one at a time, and
  switching is one click.
- **Modes change what the window is for.** The rail down the left edge moves between the IDE,
  Git, the agents, tasks and more — each a different view of the same project.

The next few pages set your colours and point out where things are. You can leave at any time
with **Skip**, and come back through **Show onboarding** in the titlebar's overflow menu.
