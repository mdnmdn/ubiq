# Project modes

A project is seen through **modes**, listed on the rail. Each is a different screen over the same
folder, and the window remembers its arrangement per mode:

- the **IDE** for files, editors and terminals,
- **Git** for the repository,
- the **agents** and **teams** screens for the harnesses at work,
- **tasks**, the **knowledge base** and the rest, as the project turns them on.

The next pages visit each mode the rail is showing. The window moves with them, so you can look
around before pressing **Next**.
