# You're set

The window is yours: the rail, the project picker, the command field, the actions, the bell, the
workspace and the status bar.

A few things worth knowing:

- **⇧F1** — or **Point at something…** in the overflow menu — names any control you point at.
- **Help** in the same menu opens the documentation for wherever you are standing.
- **Show onboarding**, also there, brings these pages back, the tour with them.

Open a project and enter the **IDE** mode, and a short walk through the project's modes follows.
